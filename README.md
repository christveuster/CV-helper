# CV-helper

> A simple tool to help generate or manage Curriculum Vitae (CV) content (project bootstrap).

## 🚀 Overview

**CV-helper** is an open-source starter project to build tools for creating or handling CVs.  
The repository currently contains basic setup *plus* Node.js dependencies like:

- `docx` — For generating `.docx` documents
- `file-saver` — To save files in the browser
- `puppeteer` — Headless Chrome automation (e.g., PDF/export workflows)

These packages provide a foundation for building features such as exporting CVs to Word or PDF formats.

> *Note:* The project does not yet include a full feature set — this README is designed to grow with it.

## 🧩 Features (Planned)

✔ Bootstrap Node/JS project  
✔ Support for `.docx` generation  
✔ File saving in client environments
